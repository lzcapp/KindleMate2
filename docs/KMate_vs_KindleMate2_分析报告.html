◆执行摘要

KMate 是原“Kindle Mate”在 2026 年的复活重做版(版权 ©2015–2026 KMate Team,开发者署名“军 黄”)。它没有停在 Windows 小工具时代,而是重建成三端产品家族:Windows + macOS 桌面端 + iPhone/iPad 移动端,并引入微信读书、Apple Books 导入与 iCloud 同步,脱离 Kindle 单一生态。

  • 定位变了:从“Kindle 标注导出工具”升级为“跨来源阅读知识库(导入→整理→复习→掌握)”。
  • 商业化了:Windows ¥58 一次性买断(15 天完整试用);Mac 免费(限最近 1,000 条)+ Pro 终身 ¥168 / 年 ¥68 / 月 ¥12;iOS 免费 + Pro 内购。个人开发者独立运营。
  • 技术栈意外:Windows 桌面版实测为 Python 3.12 + PyInstaller + mypyc 编译,UI 用 wxPython + WebView2(HTML)渲染——并非 .NET/WPF。
  • 对你项目的最大含义:KindleMate2 的立身叙事“Kindle Mate 停更后的替代品”已过时;新的差异化空间是 免费开源 + 零门槛 + 轻快原生 + 本地优先,恰好承接 KMate 商业化后流失的免费老用户。
  • 差距焦点:KMate 领先在词典(含 AI)、闪卡复习、Anki/PDF/Office 导出、标签与阅读模式;KindleMate2 的成熟底盘(解析/去重/Markdown 导出/统计/设备同步)依然扎实,建议按 P0/P1/P2 补短板(见 §6)。

01KMate 是什么:复活简史与产品画像

一句话:它回来了,而且不再只是“Kindle 伴侣”。

1.1 沿革

2.1 商业模式解读

  • “免费试用/免费额度 + 解锁”双轨:Windows 用“15 天完整试用 + 买断”;Apple 生态用“永久免费额度(1,000 条)”制造升级动机——额度限制比功能限制更“钝感”,不易劝退,但长期使用必触发付费。
  • iCloud 作为锁定层:Mac/iOS 用户数据进入个人 iCloud,迁移成本随数据量上升而上升。
  • 个人开发者(“军 黄”,非公司主体):意味着无融资压力、更新节奏自主;同时意味着售后、长期维护与跨平台质量存在个人产能上限。

03功能全景

按“导入 → 整理 → 词典 → 复习 → 统计 → 阅读 → 导出 → 同步/隐私”八条线展开。

3.1 导入源(横向扩张是这轮更新的主轴)

  • Kindle 全系设备(Paperwhite / Colorsoft / Scribe / Touch / Voyage / Oasis 等):自动识别、一键导入标注、笔记与生词本,含 Kindle 占用冲突提示。
  • Kindle App 与 Amazon Kindle 云端、微信读书(多端笔记)桌面导入。
  • Apple Books(仅 Mac,v3.8 新增):保留书名、作者、颜色标记与来源,可在数据库/阅读模式按来源独立管理。
  • 旧 KMate / KM2 数据库整库导入(继承老用户)。
  • 解析能力:13 种语言标注;重复标注自动清理(含 Kindle Scribe 场景)。

3.2 整理

  • 智能去重合并(多端合并同一本书);按 Kindle / 微信读书 / Apple Books / KMate 来源分组。
  • 分组维度:名称、作者、书籍语言、日历、学习状态;标签、颜色、多语言排序。
  • 书名/作者双击编辑 + 名称映射:改名后后续导入与 iCloud 同步自动沿用(避免旧名复现)。
  • 全文与通配符搜索(面向大型资料库,10 万+ 内容)。

3.3 词典与查词(差异化最重的一块)

  • 本地词典:桌面端 StarDict(.tar.gz)、MDict(.mdx/.mdd)、MOBI/PRC、三列 TSV、纯文本;移动端另支持 AZW。
  • 在线释义:Google 翻译、Bing 翻译、金山词霸在线、DeepL / FreeDictionary API。
  • AI 查词:Gemini / DeepSeek——生词条目可并列本地 + 在线 + AI 释义。
  • 生词来源:Kindle Vocabulary Builder,保留原始用法例句与词频。

3.4 复习 / 学习

  • 卡片或列表阅读;随机与渐进式闪卡复习(移动端优化了卡片布局:用法/释义分栏显示、切换动画)。
  • 学习状态管理 + 活动趋势(日历热力图,按日/月/年;可直接按日期筛内容)。
  • 统计洞察覆盖标注、生词、掌握度、书籍层面;移动端 Pro 含“无限统计洞察”。

3.5 阅读模式

  • 数据库整理 ↔ 阅读模式(快捷键 Ctrl+R):卡片 / 列表 / 文章视图,书籍封面、护眼主题、字体、自动折叠、快捷编辑。
  • 文章视图内嵌 Markdown 笔记、关联标注、独立书籍笔记;支持打印与卡片导出。

3.6 导出

  • Markdown / PDF / Word / Excel / CSV / TXT;桌面 + 移动覆盖面不同(Mac/iOS 的 Markdown/PDF 属 Pro)。
  • Anki 导出(v3.8 更新):支持正反面字段、卡片风格、原始 HTML 或精简释义。

3.7 同步与隐私

  • 数据库默认存本机;Mac ↔ iOS 用个人 iCloud(免费);Windows 通过数据库文件移交到移动端。
  • 隐私口径:“App 收集的数据 = 0”;Amazon 导入按需读取;在线词典仅发送当前查询词。

  1. 阅读/详情视图 = 桌面壳 + WebView2 HTML 是省力路径:WinForms/WPF 嵌 WebView2 完全同构,不必等 WPF 重写即可获得排版/护眼主题能力。
  2. MDict 接入的门槛就是 minilzo:KMate 证明了“桌面端自己做 mdx 解压”可行且代码量可控。
  3. “Python + Chromium”是它的重量包袱(数百 MB、启动慢、内存高);KindleMate2 的 .NET 8 原生 WinForms“轻、快、免运行时”是实打实的差异化卖点,README 定位更新时应正面利用。

07差距、机会与 P0/P1/P2 路线

先谈战略(定位被“复活”这件事改写),再谈功能补短板。

7.1 战略层:KindleMate2 的叙事必须更新

README 现状写的是 “Kindle Mate 停止更新后提供的替代方案”(2023 年视角)。2026 年 KMate 复活了,这句已过时,而且继续写会显得项目“跟着别人节奏走”。
  • 新定位建议:“免费、开源、无试用限制的 Kindle 标注管理工具——KMate/同类商业软件的轻快替代”。承接的正是 KMate 商业化(¥58 买断 / ¥168 终身)后不愿付费的存量用户。
  • 命名风险提示:KMate 商标与品牌已复归活跃,KindleMate2 与 “Kindle Mate” 高度相近;建议在 README 明示“与 KMate(kmate.io)/ Amazon 无关联”,避免混淆与商标纠纷隐患。
  • 护城河:MIT 开源 + 本地优先(零遥测)+ 原生轻快 + Windows 7–11 广兼容。KMate 的 Python+WebView2 栈决定了它“重”;你的 .NET 原生栈是结构性优势,应在 README/首页强调。

7.2 P0 —— 基本盘(低成本、高感知)

  1. P0 · 更新 README 定位表述:删除“停更替代”过时叙事,改为上述新定位,并加“与 KMate 无关联”声明。
  2. P0 · 补 CSV / Excel 导出:办公与数据迁移高频格式;基于现有 Markdown 导出管线扩展,工作量小、对标缺口立减。
  3. P0 · CSV 通用导入(可选):让用户能把 KMate/其他工具导出的 CSV 拉进来,直接降低“从 KMate 迁移到 KindleMate2”的换血成本——这是承接竞品流失用户的关键钩子。

7.3 P1 —— 体验补强(中等投入)

  1. P1 · 标签与 SQLite FTS5 全文搜索:tag 列已存在,补 UI 即可;LIKE → FTS5 是 SQLite 原生能力,查询体验质变。
  2. P1 · 阅读/详情视图(WebView2 路线):用 WinForms 内嵌 WebView2 渲染 Markdown 阅读模式——KMate 已证明此架构可行,不必等 WPF。
  3. P1 · 在线释义接入:哪怕先接 1 个免费源(如有道/FreeDictionary),生词详情立即“活”起来;后续再考虑 MDict(minilzo 算法已明确)。

7.4 P2 —— 重投入,建议观望/不做

  1. 闪卡/复习与 Anki 导出:Anki 生态自带工具;可引导用户走 CSV→Anki 导入,先不做原生闪卡。
  2. 移动端 / 云同步:与 iCloud 生态的正面竞争投入产出比低;守住“Windows 桌面最佳”即可。
  3. WPF 重写:README 已划线搁置;除非学习目的,不建议重启。

08结论

KMate 的复活对 KindleMate2 不是“敌人回来了”,而是“你当初存在的理由变了,但新的理由更清晰了”。

KMate 选择了一条“重而全”的路线(跨平台 + 多来源 + AI + 订阅/买断);KindleMate2 的合理身位是“轻而诚”:

  • 诚实:免费开源、本机存储、零遥测,把“不收集数据”从口号变成代码事实;
  • 轻快:原生 .NET、秒开、无 Chromium 负担,兼容 Windows 7–11;
  • 会补课:按 P0/P1 补齐导出格式、标签/FTS、阅读视图与在线释义,把“够用”推进到“好用”,同时专注服务好愿意留在桌面的深度用户。

Kindle Mate 2

Kindle 标注、笔记与生词本的内容管理程序。

A content manager for Kindle clippings, notes and vocabulary lists.

在 Kindle Mate 停止更新之后，提供一套可继续用下去的替代方案：把散落在设备里的标注与生词统一收进本地数据库， 支持检索、编辑、整理、统计与导出。基于 .NET 10 与 Avalonia 12 重写，Windows / macOS / Linux 三平台均有发布包。

After Kindle Mate stopped updating, this is a replacement that keeps working: gather clippings and vocabulary from your devices into one local database, then search, edit, organize, analyze and export them. Rewritten on .NET 10 + Avalonia 12, with release packages for Windows, macOS and Linux.

特性Features

导入、整理、输出与应用体验，四组能力覆盖日常使用全流程。

Import, organize, export and experience — four groups covering the everyday workflow.

导入标注Import clippings

解析 My Clippings.txt，保留原始行以便回溯与去重。

Parses My Clippings.txt, keeping original lines for auditing and de-duplication.

导入生词本Import vocabulary

读取 vocab.db，把生词、释义与用法一并纳入库中。

Reads vocab.db, bringing words, definitions and usage into the database.

迁移旧库Migrate old databases

支持导入 Kindle Mate、Kindle Mate 2（KM2.dat）与 KMate（km3.dat）的库。

Imports databases from Kindle Mate, Kindle Mate 2 (KM2.dat) and KMate (km3.dat).

设备直连Direct device access

从已连接的 Kindle 导入标注与生词本，也可把库内内容同步回设备。

Import clippings and vocabulary from a connected Kindle, or sync content back to the device.

编辑标注与生词Edit clippings & words

正文、笔记、释义均可直接修改，改完即落库。

Edit text, notes and definitions directly; changes are saved to the database.

删除与回收站Delete with recycle bin

支持删除单条、整本书或某个词，且删除可恢复。

Delete a single entry, a whole book or a single word — and restore it from the recycle bin.

重命名书籍Rename books

批量修正书名与作者，统一同书不同源的命名差异。

Fix titles and authors in bulk, unifying the same book imported from different sources.

库维护Database maintenance

清理、重建、备份、清空，四个动作一键完成，退出时自动备份。

Clean, rebuild, back up or empty the database in one click; a backup is taken automatically on exit.

搜索Search

按书名、作者、标注内容或笔记内容检索。

Search across book titles, authors, clipping text and notes.

导出 MarkdownExport to Markdown

按书导出为 Markdown，便于接入笔记软件与静态站点。

Export per book to Markdown, ready for note apps and static sites.

统计Statistics

自绘图表呈现阅读量、标注分布与生词积累情况。

Self-drawn charts show reading volume, clipping distribution and vocabulary growth.

夜间模式Dark mode

深浅双主题，设计令牌统一下发，跟随设置即时切换。

Light and dark themes driven by shared design tokens, switched instantly.

界面多语言UI languages

Simplified Chinese, Traditional Chinese and English resources; every string lives in resource files.

The tarball keeps executable bits; if a GUI extractor drops them, run chmod +x kindlemate2 KindleMate2.

About runtime-dependent builds: assets without the _runtime suffix require the .NET 10 runtime (Desktop Runtime on Windows). macOS ships self-contained packages only.

构建Build

需要 .NET SDK 10 或更高。

Requires .NET SDK 10 or later.

dotnet build KindleMate2.sln -c Debug
dotnet test  KindleMate2.Tests/KindleMate2.Tests.csproj

SDK 必须 ≥ 10：Avalonia 12 的 XAML 源生成器要求 Roslyn ≥ 4.14。在 SDK 8 / 9 上它会被 静默跳过（只发一条 CS9057 警告），表现为满屏 CS0103: The name 'InitializeComponent' does not exist。

SDK must be ≥ 10: Avalonia 12's XAML source generator needs Roslyn ≥ 4.14. On SDK 8 / 9 it is silently skipped (only a CS9057 warning), which shows up as a wall of CS0103: The name 'InitializeComponent' does not exist.

解决方案含 7 个工程；本仓库不含任何 git 子模块（随旧壳退役），克隆后无需 submodule update。

The solution contains 7 projects; this repository has no git submodules (retired with the legacy shells), so no submodule update is needed.

分层组织，平台专有代码一律收敛到独立程序集。完整说明见 arch.md。

Layered by design; platform-specific code is confined to a dedicated assembly. Full details in arch.md.

平台边界Platform boundary

唯一平台专有程序集是 KindleMate2.Devices.Windows。应用层只定义跨平台接口 IDeviceManager，非 Windows 平台由 NullDeviceManager 兜底 —— 如实报告“未连接”， 同步操作抛异常而不是静默失败。因此 KindleMate2.Devices.Windows.dll 只出现在 Windows 输出目录中。

The only platform-specific assembly is KindleMate2.Devices.Windows. The application layer defines just the IDeviceManager interface; non-Windows falls back to NullDeviceManager — reporting "not connected" honestly and throwing on sync instead of failing silently. That is why KindleMate2.Devices.Windows.dll only appears in Windows output.

验证手段Verification

--smoke <db> 只读自检：列表 / 详情 / 统计 / 关于 / 设置 / 搜索 / 多语言
--ops <db> … 写操作端到端：导入 → 导出 → 备份 → 重命名 → 删除 → 清理 → 重建 → 清空
单元测试跨平台 TFM 运行；CI 覆盖 windows 全量构建 + ubuntu / macOS 构建、单测与启动自检

--smoke <db> read-only self-check: list / detail / stats / about / settings / search / localization
--ops <db> … end-to-end write ops: import → export → backup → rename → delete → clean → rebuild → empty
Unit tests run on cross-platform TFMs; CI covers a full Windows build plus ubuntu / macOS build, tests and launch checks

已知边界Known limits

非 Windows 的 Kindle 设备支持尚未实现（macOS / Linux 的挂载点与 libmtp 需各自实现）， 故非 Windows 虽有发布包，设备同步仍不可用，其余功能完整；自动更新尚未迁移到 Avalonia 壳。

Kindle device support on non-Windows is not implemented yet (macOS / Linux mount points and libmtp are still to be built), so non-Windows packages ship without device sync; everything else is complete. Auto-update has not been ported to the Avalonia shell.
